Importing Complaints data into MS Access 
Las t Updated: May 2021 Page 1 of 13
 
Follow these instructions1 to download the Office of Defects Investigation (ODI) 
Complaints data and import them into Microsoft Access. ODI Complaints data 
are available in the compressed data (ZIP) format on the ODI web site. 
 
The system characteristics of the target machine will affect the speed and 
performance of the processing needed to accomplish the downloading and 
importing of the Complaints data. At least 2GB of available disk space is 
required. This space requirement will increase as more data are continually 
being added to the ODI database. 
 
Detailed field descriptions of the data file are given in Appendix A. 
 
Note: For consistency the original file name FLAT_CMPL is used throughout 
these instructions. 
 
1. Go to the following URL: 
 
 http://www-odi.nhtsa.dot.gov/downloads/index.cfm 
 
2. Select the FLAT_CMPL.zip file. 
 
3. Select Save.
